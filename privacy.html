Политика конфиденциальности yt-read

Дата последнего изменения: 2 октября 2026 года.

Кто обрабатывает данные

yt-read — персональный инструмент командной строки. Он работает только на компьютере своего владельца и используется только владельцем для чтения статистики его собственных каналов YouTube. Серверов, сайта с личным кабинетом и сторонних пользователей у приложения нет.

Какие данные приложение получает

После того как владелец сам выдал доступ своему Google-аккаунту, приложение читает через официальные API Google:

  • сведения о каналах и видео владельца: названия, даты публикации, идентификаторы;
  • показатели этих видео: просмотры, время просмотра, удержание аудитории, источники трафика, подписки, лайки, комментарии.

Запрашиваются только области доступа на чтение: https://www.googleapis.com/auth/youtube.readonly и https://www.googleapis.com/auth/yt-analytics.readonly.

Чего приложение не получает и не делает

  • не получает пароль от Google-аккаунта — вход проходит на стороне Google;
  • не читает почту, контакты, файлы, платёжные данные;
  • не загружает, не изменяет и не удаляет видео и другой контент;
  • не обращается к чужим аккаунтам.

Где данные хранятся

Токен доступа и полученные показатели хранятся в файлах на локальном диске владельца, доступных только его учётной записи (права 600). Данные не отправляются на сторонние серверы, не передаются третьим лицам, не продаются и не используются для рекламы или обучения моделей.

Как отозвать доступ

В любой момент — на странице myaccount.google.com/permissions. После отзыва приложение теряет доступ немедленно. Локальные файлы с токеном удаляются владельцем вручную.

Соответствие правилам Google

Использование и передача приложением данных, полученных из Google API, подчиняются Google API Services User Data Policy, включая требования Limited Use. Приложение также работает в соответствии с Условиями использования YouTube и Политикой конфиденциальности Google.

Privacy policy (English)

yt-read is a personal, single-user command-line tool that runs on its owner's own computer. After the owner grants access to their own Google account, the application reads information about the owner's own YouTube channels and videos and their performance metrics, using the read-only scopes youtube.readonly and yt-analytics.readonly.

The application has no server. Access tokens and retrieved metrics are stored only in local files readable by the owner's user account. No data is shared with any third party, sold, or used for advertising or for training models. The application never uploads, modifies or deletes content, and never accesses other people's accounts.

yt-read's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
