yt-read

Персональный инструмент чтения статистики собственных каналов YouTube.

Что это

Небольшая программа на Python, которая запускается на личном компьютере автора и читает показатели его собственных каналов YouTube через официальные YouTube Data API и YouTube Analytics API: просмотры, удержание зрителей, источники трафика.

Смысл в том, чтобы не переписывать цифры вручную со скриншотов YouTube Studio, а получать их в виде таблицы и сравнивать ролики между собой.

Что приложение не делает

  • не публикует и не изменяет видео, описания, комментарии;
  • не работает с чужими аккаунтами;
  • не передаёт данные никуда, кроме серверов Google, у которых их и запрашивает;
  • не имеет сервера — всё хранится локально.

Доступ

Приложение запрашивает только доступ на чтение: youtube.readonly и yt-analytics.readonly. Права на изменение не запрашиваются и не используются.

About (English)

yt-read is a personal, single-user command-line tool. It runs locally on the author's own computer and reads statistics for the author's own YouTube channels through the official YouTube Data API and YouTube Analytics API. It is read-only: it never uploads, edits or deletes anything, and it has no server component. All data stays on the local machine.
